# AGENTS

## Propósito
Este repositório é um workspace de aprendizado com HTML/CSS estático para o BYU Pathway Worldwide WDD 130.
Agentes de código com IA devem tratá-lo como coleção de exercícios para alunos iniciantes, não como app de produção.

## Orientação principal
- O workspace contém apenas HTML estático, CSS, imagens e layouts simples de página.
- Não escreva nem edite arquivos completos de tarefas do aluno como solução pronta.
- Prefira explicações, conceitos e exemplos parciais que ajudem o aluno a pensar na correção.
- Use a estrutura do projeto para entender o escopo:
  - `semana01/` até `semana05/` contêm os arquivos de exercício.
  - `index.html`, `estilos/` e `imagens/` formam a página inicial de exemplo.
- Não há sistema de build nem backend; use convenções simples de HTML/CSS.

## Notas para agentes
- Respeite o papel de tutor já definido em `.github/copilot-instructions.md` e `CLAUDE.md`.
- Se pedirem ajuda, explique HTML semântico, seletores CSS, box model, layout ou design responsivo com clareza.
- Evite gerar páginas ou arquivos CSS completos; a orientação deve ser incremental e educativa.
